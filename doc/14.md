# Electric Curtain

Electric curtain / blind motor (device type 0x14).

## Features

- Supports Curtain control (open / close / stop)
- Supports Position (0-100%)
- Supports Direction (positive / reverse)

## Customize

No customize

## Entities

### Default entity

No default entity

### Extra entities

The first three rows are controls (select / number); the last two are read-only sensors.

| EntityID                             | Class  | Description              |
| ------------------------------------ | ------ | ------------------------ |
| select.{DEVICEID}\_curtain_status    | select | Open / close / stop      |
| number.{DEVICEID}\_curtain_position  | number | Target position (0-100%) |
| select.{DEVICEID}\_curtain_direction | select | Motor direction          |
| sensor.{DEVICEID}\_software_version  | sensor | Device software version  |
| sensor.{DEVICEID}\_error_code        | sensor | Error code               |

> Note: Home Assistant may append a numeric suffix to an entity_id if it collides with an existing one, so confirm the actual id in the entity registry before using it in automations.

## Service

### midea_ac_lan.set_attribute

[![Service](https://my.home-assistant.io/badges/developer_call_service.svg)](https://my.home-assistant.io/redirect/developer_call_service/?service=midea_ac_lan.set_attribute)

Set the attribute of appliance. Service data:

| Name      | Description                                                       |
| --------- | ----------------------------------------------------------------- |
| device_id | The Appliance code (Device ID) of appliance                       |
| attribute | "curtain_status"<br />"curtain_position"<br />"curtain_direction" |
| value     | "open" / "close" / "stop"; 0-100; "positive" / "reverse"          |

Example

```yaml
service: midea_ac_lan.set_attribute
data:
  device_id: XXXXXXXXXXXX
  attribute: curtain_position
  value: 50
```
