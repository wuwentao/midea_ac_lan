# Bread Maker

Automatic bread maker (device type 0xE9).

## Features

- Supports work status, loaf size, crust color, and dosing control
- Supports bake temperature setting
- Supports cuisine and reservation timers
- Reports work stage, bottom temperature, and running / keep-warm time
- Reports response type and error code

## Service

### midea_ac_lan.set_attribute

[![Service](https://my.home-assistant.io/badges/developer_call_service.svg)](https://my.home-assistant.io/redirect/developer_call_service/?service=midea_ac_lan.set_attribute)

Set the attribute of appliance. Service data:

| Name      | Description                                                                                                                                                                                          |
| --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| device_id | The Appliance code (Device ID) of appliance                                                                                                                                                          |
| attribute | "work_status"<br />"volume"<br />"color"<br />"dosing"<br />"bake_temperature"<br />"time_cuisine_hr"<br />"time_cuisine_min"<br />"time_reserve_hr"<br />"time_reserve_min"<br />"control_cmd_code" |
| value     | an integer within the attribute range                                                                                                                                                                |

Example

```yaml
service: midea_ac_lan.set_attribute
data:
  device_id: XXXXXXXXXXXX
  attribute: bake_temperature
  value: 180
```
