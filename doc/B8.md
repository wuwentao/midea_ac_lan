# Robot Vacuum

## Supported Features

The B8 support is based on the legacy B8 LAN protocol implemented by
`midea-lan`. The newer model-specific `750004CE` protocol is not included in
this document.

- Work status and cleaning state
- Battery percentage and work time
- Cleaned area, mop state, carpet detection, and movement state
- Error type, error description, and selected hardware error flags
- Command source status (electronic control or another source)
- Do Not Disturb status and start/end time
- Side brush, filter, and roll brush remaining/life time
- Clean mode, fan level, water level, speak level, movement direction, and voice volume controls

## Service

### `midea_ac_lan.set_attribute`

The generic service can set the B8 control attributes:

| `attribute`           | Example values                             |
| --------------------- | ------------------------------------------ |
| `clean_mode`          | `auto`, `area`, `path`                     |
| `fan_level`           | `off`, `soft`, `normal`, `high`, `low`     |
| `water_level`         | `off`, `low`, `normal`, `high`             |
| `speak_level`         | `none`, `off`, `low`, `normal`, `high`     |
| `move_direction`      | `none`, `forward`, `back`, `left`, `right` |
| `work_status_control` | `charge`, `work`, `stop`, `pause`          |
| `voice_volume`        | `0`-`100`                                  |

Example:

```yaml
service: midea_ac_lan.set_attribute
data:
  device_id: XXXXXXXXXXXX
  attribute: clean_mode
  value: auto
```
