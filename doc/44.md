# Smart Panel

Screen status and screen settings for the 0x44 panel (ZKP-3INCH01). Button, scene, and device-list commands are not in the library yet, so they have no entities here.

Numeric controls accept a whole number. The largest byte the screen command will send is 254; 255 means "leave this field unchanged" and is never written. Hours are 0–23. Minutes are 0–59.

## Service

### midea_ac_lan.set_attribute

[![Service](https://my.home-assistant.io/badges/developer_call_service.svg)](https://my.home-assistant.io/redirect/developer_call_service/?service=midea_ac_lan.set_attribute)

Set one screen attribute. Fields not included in the call stay unchanged.

| Name      | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| device_id | Appliance code (Device ID)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| attribute | "screen_state"<br />"voice_control"<br />"sleep_mode"<br />"left_button"<br />"middle_button"<br />"right_button"<br />"show_button_name"<br />"close_screen_bright"<br />"sleep_mode_switch"<br />"sleep_mode_mute"<br />"left_button_keep"<br />"middle_button_keep"<br />"right_button_keep"<br />"voice_volume"<br />"brightness"<br />"night_volume"<br />"theme"<br />"auto_off_screen_type"<br />"sleep_start_hour"<br />"sleep_start_minute"<br />"sleep_duration_hour"<br />"sleep_duration_minute"<br />"left_button_work_mode"<br />"middle_button_work_mode"<br />"right_button_work_mode" |
| value     | true or false for a switch; a whole number inside the range above for a number                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |

Example

```yaml
service: midea_ac_lan.set_attribute
data:
  device_id: XXXXXXXXXXXX
  attribute: voice_volume
  value: 40
```
