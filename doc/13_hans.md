# 智能灯

## 特性

- 支持亮度调节
- 支持色温调节
- 支持灯效(场景)调节
- 支持风扇(仅风扇灯机型 M0200008)

## 自定义

设置灯的以开尔文表示的色温范围 (默认为[2700, 6500]).

```json
{ "color_temp_range_kelvin": [2000, 6800] }
```

## 实体

### 默认实体

| 实体ID                  | 类型  | 描述   |
| ----------------------- | ----- | ------ |
| light.{DEVICEID}\_light | light | 灯实体 |
| fan.{DEVICEID}\_fan     | fan   | 风扇实体(仅风扇灯机型) |

### 扩展传感器

无扩展传感器

## 服务

无服务
