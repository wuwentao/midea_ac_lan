# Dishwasher

## Entities

### Default entity

| EntityID                                        | Class  | Description                                     |
| ----------------------------------------------- | ------ | ----------------------------------------------- |
| select.{DEVICEID}\_mode_select                  | select | Wash Mode (starts the program right away)       |
| select.{DEVICEID}\_program                      | select | Program for the next start (doesn't start it)   |
| number.{DEVICEID}\_delay_minutes                | number | Delay for Start Delayed, in minutes (1-1440)    |
| switch.{DEVICEID}\_door_auto_open_setting       | switch | Door Auto-Open for the next start               |
| select.{DEVICEID}\_additional_setting           | select | Load: full or half (model `76000228` only)      |
| button.{DEVICEID}\_start                        | button | Start                                           |
| button.{DEVICEID}\_start_delayed                | button | Start Delayed                                   |
| button.{DEVICEID}\_cancel                       | button | Cancel (the running program or a delayed start) |
| button.{DEVICEID}\_pause                        | button | Pause                                           |
| button.{DEVICEID}\_resume                       | button | Resume                                          |
| sensor.{DEVICEID}\_estimated_energy_consumption | sensor | Estimated Energy Consumption (model `7600024L`) |
| sensor.{DEVICEID}\_estimated_water_consumption  | sensor | Estimated Water Consumption (model `7600024L`)  |

> To start a program: pick it in **Program**, set **Door Auto-Open** and **Load**
> if you want them, then press **Start**. For a delayed start, also set **Delay**
> and press **Start Delayed**. Without a Program choice, Start uses the program
> the dishwasher reports (the last one used). **Wash Mode** keeps its old
> behaviour and starts the selected program immediately.
>
> **Cancel** stops a running program, or cancels a pending delayed start. The
> power switch does not stop a running program on model `76000228`.
>
> Program, Delay, Door Auto-Open and Load are kept in memory and reset when Home
> Assistant restarts. They can be changed while the dishwasher is off; Program,
> Wash Mode and the buttons are available only while it's on.
> `select.{DEVICEID}_mode_select` lists the mode map reported by the device
> (limited to the seven verified modes on model `7600024L`); the per-mode
> energy/water estimates come from the product manual and accumulate as totals
> when a wash run completes.

## Service

### midea_ac_lan.set_attribute

[![Service](https://my.home-assistant.io/badges/developer_call_service.svg)](https://my.home-assistant.io/redirect/developer_call_service/?service=midea_ac_lan.set_attribute)

Set the attribute of appliance. Service data:

| Name      | Description                                 |
| --------- | ------------------------------------------- |
| device_id | The Appliance code (Device ID) of appliance |
| attribute | See the table below                         |
| value     | See the table below                         |

| attribute              | value                                                 |
| ---------------------- | ----------------------------------------------------- |
| child_lock             | true or false                                         |
| power                  | true or false                                         |
| storage                | true or false                                         |
| program                | program name, e.g. `eco_wash` (doesn't start it)      |
| delay_minutes          | 1 to 1440                                             |
| door_auto_open_setting | true or false                                         |
| additional_setting     | 0 (full load) or 2 (half load), model `76000228` only |

Example

```yaml
service: midea_ac_lan.set_attribute
data:
  device_id: XXXXXXXXXXXX
  attribute: power
  value: true
```

Example: ECO with door auto-open, starting in 2 hours

```yaml
- service: midea_ac_lan.set_attribute
  data:
    device_id: XXXXXXXXXXXX
    attribute: program
    value: eco_wash
- service: midea_ac_lan.set_attribute
  data:
    device_id: XXXXXXXXXXXX
    attribute: door_auto_open_setting
    value: true
- service: midea_ac_lan.set_attribute
  data:
    device_id: XXXXXXXXXXXX
    attribute: delay_minutes
    value: 120
- service: button.press
  target:
    entity_id: button.XXXXXXXXXXXX_start_delayed
```
