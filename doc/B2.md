# Steam Box

Built-in steam box / steam oven (device type 0xB2).

## Features

- Supports Work Status (standby / work / pause / finished / reservation / power saving)
- Supports cooking Mode (16 recipes)
- Supports timer Hours / Minutes
- Supports Temperature
- Supports child Lock
- Reports Door, Water Tank, and Steam Box (cavity) states

## Customize

No customize

## Entities

### Default entity

No default entity

### Extra entity

| EntityID                       | Class  | Description                   |
| ------------------------------ | ------ | ----------------------------- |
| select.{DEVICEID}\_work_status | select | Work status                   |
| select.{DEVICEID}\_work_mode   | select | Cooking mode                  |
| number.{DEVICEID}\_work_hour   | number | Timer hours (0-9)             |
| number.{DEVICEID}\_work_minute | number | Timer minutes (0-59)          |
| number.{DEVICEID}\_temperature | number | Target temperature (50-100°C) |
| switch.{DEVICEID}\_lock        | switch | Child lock                    |
| sensor.{DEVICEID}\_door_state  | sensor | Door state (close / open)     |
| sensor.{DEVICEID}\_water_state | sensor | Water tank state (full/empty) |
| sensor.{DEVICEID}\_box_state   | sensor | Steam box state (in / out)    |

## Service

### midea_ac_lan.set_attribute

[![Service](https://my.home-assistant.io/badges/developer_call_service.svg)](https://my.home-assistant.io/redirect/developer_call_service/?service=midea_ac_lan.set_attribute)

Set the attribute of appliance. Service data:

| Name      | Description                                                                                       |
| --------- | ------------------------------------------------------------------------------------------------- |
| device_id | The Appliance code (Device ID) of appliance                                                       |
| attribute | "work_status"<br />"work_mode"<br />"work_hour"<br />"work_minute"<br />"temperature"<br />"lock" |
| value     | Refer to the entity options / ranges above                                                        |

Example

```yaml
service: midea_ac_lan.set_attribute
data:
  device_id: XXXXXXXXXXXX
  attribute: temperature
  value: 100
```
