# Seasoning Dispenser

Automatic seasoning / spice dispenser (device type 0x70). The appliance reports
up to 8 seasoning box records (type and presence status).

## Features

- Reports the type of each of the 8 seasoning boxes
- Reports the presence status of each of the 8 seasoning boxes

> Note: dispensing seasonings and assigning box types are performed through the
> library's structured `dispense()` / `set_box_types()` commands. These are not
> exposed as Home Assistant entities, because `set_attribute` is a no-op on this
> device and Home Assistant has no generic multi-slot structured-command entity.
