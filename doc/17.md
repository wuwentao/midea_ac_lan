# Clothes Drying Rack

Electric ceiling-mounted clothes-drying rack.

## Features

- Supports Power
- Supports Raise/Lower (motor up / down / pause)
- Supports Light
- Supports Sterilize
- Supports Dry
- Supports Baking
- Supports Anion

## Customize

No customize
