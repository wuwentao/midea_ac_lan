# Steam Cooking Appliance

Steam cooking appliance (device type 0xE7), a sibling of the 0xEB family.

## Features

- Supports work status / function / fire level controls
- Supports reservation and timer settings
- Reports running time, remaining time, and work stage

## Customize

No customize

No default entity

## Service

### midea_ac_lan.set_attribute

[![Service](https://my.home-assistant.io/badges/developer_call_service.svg)](https://my.home-assistant.io/redirect/developer_call_service/?service=midea_ac_lan.set_attribute)

Set the attribute of appliance. Service data:

| Name      | Description                                                                                                                                        |
| --------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| device_id | The Appliance code (Device ID) of appliance                                                                                                        |
| attribute | "work_status"<br />"function_no"<br />"fire_level"<br />"time_reserve_hr"<br />"time_reserve_min"<br />"definite_time_hr"<br />"definite_time_min" |
| value     | integer within the entity range                                                                                                                    |

Example

```yaml
service: midea_ac_lan.set_attribute
data:
  device_id: XXXXXXXXXXXX
  attribute: fire_level
  value: 10
```
