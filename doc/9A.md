# Microwave Steam-Bake Oven

Microwave oven with steam and baking functions (device type 0x9A).

## Features

- Supports Power
- Supports Lock
- Supports Oven Light
- Supports Work Status: writable select (cancel / work / pause) plus a read-only sensor reporting all states (cancel / work / pause / end / appointment)
- Supports Mode (keep warm, baking, defrost, convection, fermentation, pizza, microwave, etc.)
- Supports Temperature setting
- Supports cooking timer (hours / minutes / seconds)
- Supports Microwave Power (watt)
- Supports Food Weight
- Reports Current Temperature
- Reports Error Code

## Customize

No customize

## Service

### midea_ac_lan.set_attribute

[![Service](https://my.home-assistant.io/badges/developer_call_service.svg)](https://my.home-assistant.io/redirect/developer_call_service/?service=midea_ac_lan.set_attribute)

Set the attribute of appliance. Service data:

| Name      | Description                                                                                                                                                   |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| device_id | The Appliance code (Device ID) of appliance                                                                                                                   |
| attribute | "power"<br />"lock"<br />"furnace_light"<br />"work_status"<br />"mode"<br />"temperature"<br />"hour"<br />"minutes"<br />"second"<br />"watt"<br />"weight" |
| value     | Value to set                                                                                                                                                  |

Example

```yaml
service: midea_ac_lan.set_attribute
data:
  device_id: XXXXXXXXXXXX
  attribute: temperature
  value: 180
```
