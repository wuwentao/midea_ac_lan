# Tea Brewer

Automatic tea / beverage brewer (device type 0xF1).

## Features

- Supports Power
- Supports Speed
- Supports Work / Keep Warm Temperature
- Supports Work / Keep Warm / Appointment Time
- Supports Recipe Code and Work Mode
- Reports response, work status / step / stage, lid and cup status, current time and temperature

## Customize

No customize

## Service

### midea_ac_lan.set_attribute

[![Service](https://my.home-assistant.io/badges/developer_call_service.svg)](https://my.home-assistant.io/redirect/developer_call_service/?service=midea_ac_lan.set_attribute)

Set the attribute of appliance. Service data:

| Name      | Description                                                                                                                                                            |
| --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| device_id | The Appliance code (Device ID) of appliance                                                                                                                            |
| attribute | "power"<br />"speed"<br />"set_work_temp"<br />"set_keep_warm_temp"<br />"set_work_time"<br />"set_keep_warm_time"<br />"appoint_time"<br />"code_id"<br />"work_mode" |
| value     | true/false for "power"; an integer within range for the numeric attributes                                                                                             |

Example

```yaml
service: midea_ac_lan.set_attribute
data:
  device_id: XXXXXXXXXXXX
  attribute: power
  value: true
```
