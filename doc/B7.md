# Smart Gas Stove

## Features

- Reports left and right burner status, gear, work mode, and temperature
- Reports surplus and work timers for each burner
- Reports gas warning, smart boil-dry protection, and menu mark flags
- Reports error and tips codes
- Controls panel lock (on/off)
- Controls left and right burner power (momentary ignite/toggle)
- Controls left and right burner gear (0–255)
- Controls left and right burner temperature set point (0–65535 °C)

## Customize

```json
{
  "refresh_interval": 30
}
```

- `refresh_interval`: polling interval in seconds (default: 30).
