# Light

## Features

- Supports Brightness
- Supports Color Temperature
- Supports Effect (Scene)
- Supports Fan (fan-light model `M0200008` subtype 0 only; subtype 1 does not
  expose a fan entity)

## Customize

Set the light's color temperature range in Kelvin ([2700, 6500] by default).

```json
{ "color_temp_range_kelvin": [2000, 6800] }
```

## Entities

### Default entity

| EntityID                | Class | Description                            |
| ----------------------- | ----- | -------------------------------------- |
| light.{DEVICEID}\_light | light | Light entity                           |
| fan.{DEVICEID}\_fan     | fan   | Fan entity (`M0200008` subtype 0 only) |

### Extra entity

No extra entity
